## Monitoring & Evaluation

### Building the M&E plan

1. Identify project goals and objectives
2. Define indicators
3. Define data collection methods and timeline
4. Assign M&E roles and responsibilities
5. Create an analysis plan and template
6. Plan for dissemination and donor reporting

### Reporting cadence

| Frequency | Purpose |
|---|---|
| Monthly | Progress report on day-to-day implementation |
| Quarterly | Compares approved work plan against actual performance; flags constraints and remedial action |
| Semi-annual | Account of actual implementation with clear corrective recommendations |
| Annual | Assesses outputs, outcomes, and the most significant changes the project has driven |

This cadence exists to keep donors and stakeholders informed at a level of detail appropriate to the time horizon — tactical monthly updates, strategic annual assessments.
